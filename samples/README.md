# Sample photographs / 样片

Three HLG Photo pairs, shot by **Baizhi-Angelica** on a Panasonic DC-S5 with an
APO-SUMMICRON-SL 35 mm f/2 ASPH.

| File | Scene | Why it is here |
|---|---|---|
| `_PAN0301` | Harbour at dusk | bright sky, deep shadows, saturated boat colours |
| `_PAN0766` | Interior with a backlit window | extreme dynamic range |
| `_PAN0976` | Lake and hills | smooth gradients, colour transition check |

Each pair contains the original `.HSP` and the `.HEIC` produced by this tool from it.
The `.HEIC` files are byte-identical to what `convert.bat` produces, so you can use
them as reference output.

三组 HLG Photo 样片，由 **Baizhi-Angelica** 使用松下 DC-S5 与 APO-SUMMICRON-SL 35 mm f/2
镜头拍摄。每组包含原始 `.HSP` 和本工具生成的 `.HEIC`；`.HEIC` 与运行 `convert.bat`
得到的文件逐字节一致，可作为参考输出。
